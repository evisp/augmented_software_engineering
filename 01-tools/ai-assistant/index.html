    AI Assistant¶

    40 min Tools Needs: VS Code connected to WSL, a GitHub account

    You will use three assistants in this program, and each has a different job. This tutorial sets them up and shows you how to use them without letting them do your learning for you.

    Why this matters¶

    Professional developers use AI every day: to explain unfamiliar code, draft boilerplate, find bugs and write tests. You will too, from the first week.

    AI can produce something that looks right very quickly. What it cannot do is check its own assumptions, know what your project actually needs, or take responsibility for the result. That part is yours. A project that passes the Checker but that you cannot explain will not survive a peer review, and it will not survive a job interview either.

    Three assistants, three jobs¶

    Copilot sees the files you have open, so it is the fastest way to ask about your code. Claude or ChatGPT have more room for a conversation, so they are better for understanding a concept or an error properly. Clippy knows Holberton's projects and is built to make you think: it asks questions and gives you the next step, not the answer.

    How to use any of them¶

    Whichever assistant you open, the same loop applies.

    The step people skip is Read. If you cannot say what a line does, you are not ready to test it, and you are certainly not ready to commit it.

    Step 1: Switch on GitHub Copilot in VS Code¶

    Copilot is built into VS Code. You only need to sign in.

    1. Open VS Code connected to WSL, so the bottom left says WSL: Ubuntu.
    2. Hover over the Copilot icon in the status bar and choose Use AI Features.
    3. Sign in with your GitHub account and approve the request in the browser.

    If your account has no Copilot plan, it is enrolled in Copilot Free automatically, which gives you a monthly allowance of suggestions and chat. If you are a student, you can also apply through GitHub Education for the free student plan. Plans and limits change often, so check the current details there.

    Two shortcuts to learn now:

    Keys What it opens
    Ctrl+Alt+I Chat view: a conversation about your project
    Ctrl+I Inline chat: ask about, or change, the selected code

    Consider turning off inline suggestions while you learn the basics

    Grey suggestions that appear as you type are useful once you know the language. In your first weeks they type the answer before you have thought of it, and you learn the syntax much more slowly. Hover over the Copilot icon in the status bar to switch code completions off. Chat keeps working, so you can still ask questions.

    Step 2: Set up a browser assistant¶

    Create a free account on Claude or ChatGPT. One is enough; pick whichever you prefer. Keep it pinned in your browser next to the intranet.

    Use it for the bigger questions:

    • Explain a concept from your project in plain language.
    • Read an error message with you and say what it means.
    • Compare two ways of solving something and their trade-offs.

    Step 3: Meet Clippy¶

    Clippy lives on the intranet, on your project pages. It knows what each task asks for and is built to coach you rather than solve it.

    Tell Clippy what you are trying to do, what you have tried and where you are stuck. It answers with questions and the next step of reasoning, not with code. That is deliberate. Use it when you are stuck on how to think about a task, before you go looking for code anywhere else.

    Ask well¶

    A vague question gets a vague answer. A good prompt gives the assistant four things: what you are working on, what you tried, what happened, and what kind of help you want.

    Explain an error

    I'm writing a Python script on Ubuntu for a beginner project.
Running `python3 0-add.py` gives this error:

TypeError: unsupported operand type(s) for +: 'int' and 'str'

Explain what the error means and where to look in my code.
Don't rewrite the code for me.

    Ask for a hint, not the answer

    My task: write a function that returns the largest number in a list
without using max(). I tried looping over the list, but I don't know
what to compare each number against. Give me a hint for the next
step, not the solution.

    Review code you wrote

    Here is my solution to a task. It passes, but review it like a
senior developer: is anything unclear, fragile or unnecessary?
Explain each point. Don't give me a rewritten version.

[paste your code]

    Notice the last line of each prompt. Saying what you do not want is the easiest way to keep the learning on your side.

    Rules for Holberton projects¶

    • Do

      • Ask it to explain concepts, docs and error messages
      • Ask for a hint when you are stuck
      • Ask it to review code you wrote yourself
      • Ask it for test cases you had not thought of
      • Check what it says against the docs or by running it

    • Don't

      • Paste a task and submit whatever comes back
      • Commit a line you cannot explain
      • Paste passwords, tokens or .env files into any assistant
      • Paste a classmate's code without asking them
      • Trust a confident answer you have not tested

    Your peers and mentors will ask you to explain your code. "The AI wrote it" is not an explanation.

    When something goes wrong¶

    There is no Copilot icon in the status bar

    Update VS Code with Help > Check for Updates, then restart it. If the icon is still missing, press Ctrl+Shift+P and run Chat: Open Chat, which also offers the sign-in.

    Copilot says I have reached my limit

    The free plan has a monthly allowance. Use the browser assistant or Clippy until it resets, or apply for the student plan through GitHub Education.

    The answer looks right but the code fails

    That happens often. Assistants guess at versions, file names and what your task requires. Paste the exact error back and say what you expected, or read the docs for the function it used.

    Check yourself¶

    1. The Copilot icon in the status bar shows you are signed in.
    2. Open hello.py, select the print line, press Ctrl+I and ask explain this line. Read the answer.
    3. In Claude or ChatGPT, ask: What is the difference between running python3 hello.py and ./hello.py on Linux? Then try both in your terminal and see whether the answer was right.
    4. Open any project on the intranet and ask Clippy how to start the first task. Notice that it asks you questions back.

    Quick reference¶

    Assistant Where Use it for Open it with
    GitHub Copilot VS Code Questions about your open code Ctrl+Alt+I, Ctrl+I
    Claude or ChatGPT Browser Concepts, errors, comparing approaches claude.ai, chatgpt.com
    Clippy Intranet project pages Reasoning through a task On the project page
