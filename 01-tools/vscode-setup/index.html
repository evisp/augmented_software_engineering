    VS Code¶

    30 min Tools Needs: WSL set up

    VS Code is the editor you will use for every project in this program: Python, SQL, HTML, CSS and JavaScript. It installs on Windows and works inside Ubuntu, so you get a familiar window and a Linux machine underneath it.

    Why this matters¶

    A good editor does a lot of quiet work. It catches typos before the Checker does, keeps your formatting consistent, and puts a terminal, Git and an AI assistant in the same window as your code. Set it up properly once and you stop thinking about it.

    The window at a glance¶

    1. Activity bar. Switches the side bar between Explorer, Search, Source Control, Extensions and Copilot Chat.
    2. Side bar. Shows whatever the activity bar picked. Most of the time, the files in your project.
    3. Editor. Where you write code. You can split it to see two files at once.
    4. Panel. The terminal lives here. It is a real Ubuntu terminal, the same one you used in the WSL tutorial.
    5. Status bar. The bottom left corner must say WSL: Ubuntu. That label tells you your code runs on Linux. Check it whenever something behaves strangely.

    Step 1: Install VS Code on Windows¶

    Download it from code.visualstudio.com and run the installer. Tick these boxes when offered:

    • Add "Open with Code" action to the file context menu
    • Add "Open with Code" action to the directory context menu
    • Add to PATH

    The last one lets you type code . in a terminal to open the current folder. You will use it constantly.

    Install VS Code on Windows only. Do not install it inside Ubuntu.

    Step 2: Install the WSL extension¶

    1. Open VS Code and press Ctrl+Shift+X to open Extensions.
    2. Search for WSL, published by Microsoft, and click Install.

    Step 3: Open your projects folder from Ubuntu¶

    Open the Ubuntu terminal and run:

    cd ~/holberton
code .

    The first time, Ubuntu downloads a small helper called the VS Code Server. Give it a minute. A VS Code window opens with your holberton folder in the Explorer.

    Look at the bottom left corner. It should say WSL: Ubuntu. Open the terminal with Ctrl+` (the key above Tab). The prompt looks like this:

    yourname@LAPTOP:~/holberton$

    That is Linux. Everything you type there runs on Ubuntu.

    Step 4: Install extensions on the Linux side¶

    Extensions install separately on each side. Having one on Windows does not mean it works in the WSL window.

    Open Extensions with Ctrl+Shift+X in the WSL window and install these. Each one shows an Install in WSL: Ubuntu button.

    Extension Publisher What it gives you
    Python Microsoft Highlighting, error hints and the Python interpreter
    ESLint Microsoft Flags JavaScript mistakes as you type

    Later modules add a few more. Keep the list short: every extension slows the editor down a little.

    Step 5: Settings that keep the Checker happy¶

    Holberton's style checkers reject lines longer than 79 characters, spaces at the end of a line, and files without a final newline. VS Code can handle all three for you.

    Press Ctrl+Shift+P, run Preferences: Open User Settings (JSON), and add these lines inside the curly braces:

    {
  "files.autoSave": "afterDelay",
  "files.insertFinalNewline": true,
  "files.trimTrailingWhitespace": true,
  "editor.rulers": [79],
  "editor.renderWhitespace": "trailing",
  "[python]": { "editor.tabSize": 4 },
  "[javascript]": { "editor.tabSize": 2 }
}

    If the file already has settings, add the new lines among them and separate each line with a comma. Save with Ctrl+S.

    The ruler draws a thin line at column 79. Keep your code to the left of it.

    Step 6: Run your first file¶

    In the Explorer, click the new-file icon and create hello.py:

    print("Hello, Holberton")

    Run it in the terminal:

    python3 hello.py

    The output appears right below. The Checker runs your files from a terminal exactly like this, so get used to running them the same way rather than with a Run button.

    AI in the loop

    VS Code has GitHub Copilot built in. You switch it on in the next tutorial, together with a browser assistant and Clippy, and learn when to use which.

    Shortcuts worth knowing¶

    Keys What it does
    Ctrl+Shift+P Command palette. Everything VS Code can do is in here
    Ctrl+P Jump to a file by typing part of its name
    Ctrl+` Show or hide the terminal
    Ctrl+B Show or hide the side bar
    Ctrl+Shift+E File explorer
    Ctrl+/ Comment or uncomment the selected lines
    Alt+Up / Alt+Down Move the current line up or down
    Ctrl+D Select the next match of the selected word

    When something goes wrong¶

    code: command not found in Ubuntu

    Close and reopen the Ubuntu terminal. If it still fails, reinstall VS Code on Windows and make sure Add to PATH is ticked, then restart the laptop.

    The status bar does not say WSL: Ubuntu

    You opened the folder from Windows. Close the window, open the Ubuntu terminal, and run cd ~/holberton && code . again.

    An extension is installed but does nothing

    It is installed on the Windows side only. Open Extensions in the WSL window and click Install in WSL: Ubuntu.

    Everything is slow, and Git takes seconds

    Your project is under /mnt/c. Move it into ~/holberton, as in the WSL tutorial.

    Check yourself¶

    1. The bottom left corner says WSL: Ubuntu.
    2. In the VS Code terminal, pwd prints /home/yourname/holberton.
    3. python3 hello.py prints Hello, Holberton.
    4. Type a line longer than the ruler in hello.py. You can see where it crosses column 79.
    5. Add a few spaces at the end of a line and save. They disappear.
