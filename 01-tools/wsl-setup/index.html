    WSL¶

    35 min Tools Needs: Windows 10 (2004+) or 11, admin rights

    WSL, the Windows Subsystem for Linux, runs a real Ubuntu inside Windows. Every project in this program is written, run and checked on Linux, so this is where your code will live.

    Why this matters¶

    Almost every server, cloud machine and container you will deploy to runs Linux. Holberton projects are tested on Ubuntu too, so code that works on Windows can still fail the Checker because of a path, a line ending or a missing command.

    WSL removes that gap. You keep the Windows you are used to for your browser, Slack and VS Code. Your code runs on Linux, and the two share files. This setup is required for the program.

    On a Mac or Linux?

    You do not need WSL. macOS and Linux already have a Unix terminal. Go straight to VS Code and use your normal terminal wherever these tutorials say Ubuntu terminal.

    How the pieces fit¶

    One thing to hold on to: the window is Windows, the code is Linux.

    Step 1: Check your Windows¶

    Press Win+R, type winver and press Enter. You need Windows 11, or Windows 10 version 2004 or later. If you are on an older version, run Windows Update first.

    Then open Task Manager with Ctrl+Shift+Esc, go to Performance, then CPU, and find the line Virtualization. It should say Enabled. If it says disabled, see When something goes wrong before you continue.

    Step 2: Install WSL¶

    Right-click the Start button and choose Terminal (Admin). On Windows 10 this may be called Windows PowerShell (Admin). Then run:

    wsl --install

    This turns on the Windows features WSL needs, downloads the Linux kernel and installs Ubuntu. It takes a few minutes. Restart when it asks.

    Step 3: Create your Linux user¶

    After the restart, Ubuntu opens by itself and asks for a username and a password.

    • Username: lowercase, no spaces. It does not have to match your Windows name.
    • Password: pick one you will remember. You type it every time you run a command with sudo.

    Linux shows nothing while you type a password, not even dots. That is normal. Type it and press Enter.

    Check it worked. Back in the Windows terminal, run:

    wsl --list --verbose

    You want to see Ubuntu with version 2:

      NAME      STATE           VERSION
* Ubuntu    Running         2

    Step 4: Update Ubuntu and install the basics¶

    Open Ubuntu from the Start menu. Everything from here on runs in the Ubuntu terminal, not in PowerShell.

    Update the package lists and upgrade what is installed:

    sudo apt update && sudo apt upgrade -y

    Then install the tools the first projects need:

    sudo apt install -y build-essential git curl python3 python3-pip python3-venv

    Check them:

    python3 --version
git --version

    You should see Python 3.10 or later, and any recent Git version.

    AI in the loop

    When an install fails, copy the full error message into Claude or ChatGPT and ask what it means and what each suggested fix does. Run a fix only once you understand what it changes. Pasting commands you do not understand into a terminal with sudo is how people break their setup.

    Step 5: Make your projects folder¶

    This is the one WSL rule worth memorising.

    Keep your projects in your Linux home folder. Files there live on the Linux filesystem and are fast. Files under /mnt/c live on the Windows filesystem, and every read crosses a bridge. Git and Python become noticeably slow, and file permissions behave strangely.

    mkdir -p ~/holberton
cd ~/holberton
pwd

    You should see /home/yourname/holberton. That is where every project in this program goes.

    To look at the folder in Windows Explorer, run:

    explorer.exe .

    The dot means this folder. Explorer opens it under Linux in the sidebar.

    Make Ubuntu your default terminal

    In Windows Terminal, open Settings, set Default profile to Ubuntu and save. Every new terminal tab then opens straight into Linux.

    When something goes wrong¶

    wsl --install fails, or Virtualization says disabled

    Virtualisation is turned off in your BIOS. Restart, enter the BIOS setup (usually F2, F10 or Del while the laptop starts), and enable Intel VT-x or AMD-V, sometimes called SVM. Save, restart and run wsl --install again.

    wsl --list --verbose shows version 1

    Run wsl --set-version Ubuntu 2 in PowerShell and wait. It can take a few minutes. Then run wsl --set-default-version 2 so future installs use version 2.

    Ubuntu opens and closes straight away

    Run wsl --update in PowerShell, restart the laptop and open Ubuntu again.

    I forgot my Linux password

    In PowerShell, run wsl -u root to open Ubuntu as the administrator account. Then run passwd yourname, set a new password, and type exit.

    Could not get lock /var/lib/dpkg/lock

    Another update is running in the background. Wait a minute and run your apt command again.

    Check yourself¶

    1. In PowerShell, wsl --list --verbose shows Ubuntu with version 2.
    2. In the Ubuntu terminal, cd ~/holberton && pwd prints /home/yourname/holberton, not a /mnt/c path.
    3. python3 --version prints 3.10 or later.
    4. git --version prints a version number.
    5. explorer.exe . opens your holberton folder in Windows Explorer.

    Quick reference¶

    Command Where What it does
    wsl --install PowerShell (Admin) Installs WSL and Ubuntu
    wsl --list --verbose PowerShell Shows installed Linux versions
    wsl --update PowerShell Updates WSL itself
    sudo apt update && sudo apt upgrade -y Ubuntu Updates Ubuntu's packages
    sudo apt install -y name Ubuntu Installs a package
    cd ~/holberton Ubuntu Goes to your projects folder
    explorer.exe . Ubuntu Opens the current folder in Windows Explorer
