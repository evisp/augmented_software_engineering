    Data & APIs¶

    Learn to keep data and share it: read and write files, store and query data in a relational database, map it to Python objects, and serve it over the web through a REST API.

    Software Development 60 h 6 projects Needs: Object-Oriented Design

    Tutorials published1 of 6

    How these tutorials work¶

    The projects on the Holberton intranet are where you build. These tutorials are where you learn the basics first, and practise them on small examples until they feel natural.

    • Learn step by step

      One idea per step, each with a short example and the real output it prints. Run every example yourself.

    • Try it

      Most steps end with a short exercise. Write your answer first, then open the collapsed answer to compare.

    • Practise

      Each tutorial ends with a practice set, from easy to harder, on the same data you used along the way.

    The practice data: a small library¶

    Every tutorial in this module uses the same theme: a small library with books, authors and the people who borrow them. You download the files you need at the start of each tutorial, and you can download them again whenever you break something.

    Tutorial Practice data
    File Handling books.txt, a list of ten books; catalog.json, the same kind of data as JSON
    SQL tutorials A SQLite database of the library: books, authors, members and loans

    What you need

    Python 3, a WSL terminal and VS Code, as set up in Tools and Python Fundamentals. The SQL tutorials show you how to install SQLite.

    AI in the loop

    This module is where code starts touching real data. Assistants write file, SQL and API code quickly, and a single wrong mode, a missing WHERE or an unvalidated request can destroy or expose data. Before you run anything an assistant wrote, ask: what does this do to the data if it fails halfway? Read it until you can answer.
