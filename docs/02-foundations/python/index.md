## How to work through a project

<div class="h-journey" markdown>

1.  **Read**

    Work through the tutorial, typing every example yourself.

2.  **Build**

    Do the tasks on the intranet, in your own repository.

3.  **Check**

    Run `pycodestyle`, compare your output, then let the Checker run.

4.  **Explain**

    Go through the tutorial's checklist out loud, ideally to a peer.

</div>

!!! ai "AI in the loop"

    In this module, use assistants to *explain*, not to *write*. Ask
    what an error means, ask for a hint, or ask it to trace your loop.
    Clippy on the intranet is built for exactly this. If you can only
    get a task to work by pasting generated code, you are not ready for
    the next project yet.
