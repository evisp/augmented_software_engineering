# Roadmap

Five stages, each building on the one before. You start with the tools,
learn the fundamentals, build real software, bring AI into the workflow,
and finish with projects that show what you can do.

!!! info "Curriculum in progress"

    The program is being finalized. Stages and topics below show the
    intended path; details will change as each section is published.
    Stages marked in grey are not open yet.

## Learning path

<div class="tri-band">
  <span class="tri-band__num">1</span>
  <span class="tri-band__role">Tools</span>
  <span class="tri-band__when">Set up</span>
</div>

A working development environment and the tools used throughout the
program.

<span class="badge">Terminal</span>
<span class="badge">WSL</span>
<span class="badge">VS Code</span>
<span class="badge">Git</span>
<span class="badge">GitHub</span>

By the end of this stage you can:

- open a terminal and move around your machine with confidence
- write, run and debug code in VS Code
- track your work with Git and publish it on GitHub

[:octicons-arrow-right-24: Go to Tools](01-tools/index.md)

<div class="tri-band tri-band--upcoming">
  <span class="tri-band__num">2</span>
  <span class="tri-band__role">Foundations</span>
  <span class="tri-band__when">Learn the core</span>
</div>

The core knowledge every software engineer relies on, whether or not an
assistant is writing the first draft.

By the end of this stage you can:

- write programs that use variables, control flow, functions and data structures
- reason about how a program runs and why it fails
- read unfamiliar code and explain what it does

<div class="tri-band tri-band--upcoming">
  <span class="tri-band__num">3</span>
  <span class="tri-band__role">Software Development</span>
  <span class="tri-band__when">Build</span>
</div>

How software is designed, built, tested, debugged and maintained by a
team.

By the end of this stage you can:

- structure a project so that others can read and change it
- write tests and use them to catch regressions
- work through pull requests and code review

<div class="tri-band tri-band--upcoming">
  <span class="tri-band__num">4</span>
  <span class="tri-band__role">Augmented Engineering</span>
  <span class="tri-band__when">Augment</span>
</div>

AI as part of the everyday engineering workflow, used with judgement.

By the end of this stage you can:

- use AI assistants to plan, write, refactor and document code
- review generated code for correctness, security and style
- decide when to use an assistant and when not to

<div class="tri-band tri-band--upcoming">
  <span class="tri-band__num">5</span>
  <span class="tri-band__role">Projects</span>
  <span class="tri-band__when">Ship</span>
</div>

Practical projects that bring the different skills together into a
portfolio.

By the end of this stage you can:

- take a project from idea to a deployed, documented result
- show your work and explain the decisions behind it
