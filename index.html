    Augmented Software Engineering¶

    Build software. Use AI. Understand what you build.

    A practical foundation in software engineering, the tools professionals use every day, and the AI-assisted workflows that are changing how software gets made.

    Start here View roadmap

    What this is¶

    This handbook is the learning environment for the Augmented Software Engineering program at Holberton School Albania.

    It teaches software engineering the way it is practised now: with AI assistants in the editor, the terminal and the code review. You will use those assistants from the start. You will also learn enough of the fundamentals to check what they produce, fix it when it is wrong, and explain every line you ship.

    How you will work¶

    • Build first

      Every topic ends in something that runs. You learn a concept by using it, breaking it and fixing it.

    • AI as a pair, not a replacement

      You will prompt, review and correct AI output. The assistant writes a draft; you are responsible for what gets merged.

    • Understand what you ship

      If you can't explain it, you don't commit it. Reading code and debugging matter as much as writing it.

    • Work like a professional

      Git, pull requests, code review and a real development environment from the first day.
